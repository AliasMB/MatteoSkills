# Collaudo TwinCAT HMI TE2000

1. Parti dai sorgenti del progetto HMI e dall'URL della Live View attiva. Verifica che il server serva la versione corrente di vista e script. Su ProgettoCN la porta di sviluppo era 3000. Ricava la porta dal progetto o dai listener attivi quando cambia ambiente.
2. Prima dei clic, leggi via WebSocket HMI i simboli necessari e confrontali con il PLC previsto. Se il server restituisce `SYMBOL_NOT_MAPPED` dopo una modifica, verifica i mapping della configurazione caricata dal server di Engineering. Il browser può servire i file aggiornati mentre il server usa ancora i mapping precedenti. Il server di sviluppo può aggiornare i mapping a runtime tramite `TcHmiSrv.Config::SYMBOLS`. Leggi il valore attivo, conserva le voci già presenti, integra le sole modifiche e rileggi i simboli interessati. [Configurazioni Beckhoff](https://infosys.beckhoff.com/content/1033/te2000_tc3_hmi_engineering/2669771659.html)
3. Per provare campi, pulsanti e messaggi, usa Playwright se già disponibile oppure Chrome in background con un profilo temporaneo, `--headless` e `--remote-debugging-port=0`. Con Node e DevTools Protocol leggi `DevToolsActivePort`, apri il WebSocket della pagina via `/json/list` e usa selettori DOM stabili. Usa eventi browser per digitazione, clic e pressione/rilascio. Leggi gli stati del DOM e, per il test integrato, gli stati PLC corrispondenti. Riporta le sole asserzioni e gli errori. [Chrome Headless](https://developer.chrome.com/docs/chromium/headless)
4. Per le prove che inviano comandi, verifica prima il target di simulazione e le condizioni iniziali. Prova una funzione alla volta. Per il jog osserva l'arresto al rilascio. Per un ciclo osserva il ritorno a riposo pronto. Usa XAE visibile per attività di Engineering che richiedono il Designer o le funzioni del progetto.

Per la diagnosi, identifica URL e processo della stessa istanza, poi verifica HTTP, simboli HMI e consensi PLC. Distingui server irraggiungibile, licenza della stessa istanza, simbolo non mappato e consenso assente. Prima di attribuire una causa ripeti il controllo sull'istanza interessata.
